# Staff Guide: Library Seat Dashboard

This guide shows library staff how to use the seat dashboard.
You do not need to know programming.

## Opening the dashboard
Open a web browser.
Type http://localhost:5000 in the address bar.
Press Enter.
The login page will appear.

[screenshot here]

## Logging in
Type your username.
Type your password.
Click Login.

If the password is wrong, a message will appear.
Check your spelling and try again.
Make sure Caps Lock is off.
If it still does not work, tell Con.

[screenshot here]

## The Live page
The Live page shows every seat in the library.

- A green seat is vacant. Nobody is sitting there.
- A red seat is taken. Someone is sitting there.

At the top of the page you will see three numbers:

- Total: all the seats in the room
- Taken: seats that are in use
- Vacant: seats that are free

The page shows the newest seat reading.

[screenshot here]

## The FULL banner
A big banner that says "LIBRARY FULL" appears at the top.
It shows only when every seat is taken.
The vacant count is 0 at that time.

When you see it, staff may:

- Tell new students that the library is full.
- Ask students to come back later.
- Remind students to leave when they are done.

The banner goes away when a seat becomes vacant.

[screenshot here]

## The History page
Click History to open this page.
It shows past readings from the system.
Each row has the time, the seat name, and if the seat was taken or vacant.
Use it to see when the library is busy.

[screenshot here]

## If something looks wrong
The page is not updating:
- Refresh the page.
- If nothing changes, tell Con.

The seat count looks wrong:
- Look at the room and compare it to the dashboard.
- Write down the time and the seat name.
- Tell Con.

Con is the person to tell for any problem.
If you can, send a photo of the screen.

## Logging out
Click Logout.
You will go back to the login page.
Always log out when you are done.
This keeps the dashboard private.
